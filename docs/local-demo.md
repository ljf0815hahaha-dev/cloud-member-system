# 本地演示说明

认证审核期间，项目已启用本地开发模式，不依赖 CloudBase 环境。

## 店员/店长 H5

本地访问地址：

```text
http://127.0.0.1:8765/
```

演示账号：

| 角色 | 账号 | 密码 |
|------|------|------|
| 店长 | manager | 123456 |
| 店员 | staff | 123456 |

演示会员手机号：

```text
13800138000
```

可测试：

1. 按手机号查询会员，初始余额 ¥680.00。
2. 录入充值并刷新余额。
3. 输入大于余额的消费金额，验证“余额优先 + 线下补付”计算。
4. 选择图片并录入贴膜记录，本地模式把图片保存在浏览器 localStorage，仅用于演示。
5. 使用店长账号打开“店长管理”，新增店员、公告、消费项目，并作废流水。

如需重新初始化演示数据，在浏览器开发者工具 Console 执行：

```js
MockStaffService.reset()
location.reload()
```

## 顾客微信小程序

在微信开发者工具中导入：

```text
E:\car1\cloud-member-system
```

当前 `miniprogram/app.js` 设置为：

```js
devMode: true
```

打开小程序后点击“手机号登录”，会显示“使用演示会员登录”。登录后可查看：

- ¥680.00 演示余额
- 充值与贴膜消费流水
- 首页公告轮播图
- 贴膜记录和演示照片

## 切换正式云环境

认证通过、CloudBase 环境创建完成后：

1. 将 `miniprogram/app.js` 中 `devMode` 改为 `false`。
2. 将 `staff-h5/config.js` 中 `devMode` 改为 `false`。
3. 在两个文件中填入真实 `envId`。
4. 按 `deployment.md` 创建数据库并部署云函数。
